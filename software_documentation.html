Image Deblurring & Restoration Studio

Traditional Digital Image Processing filter দিয়ে ছবির noise, blur, low contrast ও exposure সমস্যা ঠিক করার একটি single-file Python desktop সফটওয়্যার। ছবি আপলোড করলে এটি নিজে বিশ্লেষণ করে ফিল্টার প্রস্তাব করে ও প্রয়োগ করে; আপনি সবকিছু ম্যানুয়ালিও নিয়ন্ত্রণ করতে পারেন।A single-file Python desktop application that fixes noise, blur, low contrast and exposure problems with traditional Digital Image Processing filters. When you upload an image it analyses it, recommends filters and applies them; you can also control everything manually.

  • স্বয়ংক্রিয় বিশ্লেষণ ও কারণসহ সুপারিশAutomatic analysis and recommendations with reasons
  • ১৫টি ফিল্টার: নয়েজ কমানো, deblur, sharpen, contrast/exposure15 filters: noise removal, deblur, sharpen, contrast/exposure
  • Manual Override: ১টি বাধ্যতামূলক + ১টি ঐচ্ছিক ফিল্টারManual Override: one required + one optional filter
  • বহু-ধাপের সম্পাদনযোগ্য Filter PipelineMulti-step, editable Filter Pipeline
  • Test Images: কৃত্রিম নয়েজ/ব্লার দিয়ে পরীক্ষাTest Images: try it with synthetic noise/blur
  • Reference ছবি থাকলে PSNR / SSIM / MSEPSNR / SSIM / MSE when a Reference image is loaded
  • বড় ছবির জন্য Actual size ও scrollActual size and scrolling for large images

ইনস্টল ও চালানোInstall & Run

প্রয়োজনRequirementবিবরণDetails
Python৩.৮ বা নতুন (tkinter সহ)3.8 or newer (with tkinter)
Librariesopencv-python, numpy, scipy, pillow, scikit-image
OSWindows / macOS / Linux
pip install opencv-python numpy scipy pillow scikit-image
python image_restoration.py

scikit-image না থাকলেও অ্যাপ চলে, তবে Richardson-Lucy কাজ করে না এবং PSNR/SSIM-এর বদলে শুধু MSE দেখায়। Linux-এ tkinter আলাদা: sudo apt install python3-tk।The app also runs without scikit-image, but Richardson-Lucy does not work and only MSE is shown instead of PSNR/SSIM. On Linux tkinter is separate: sudo apt install python3-tk.

দ্রুত শুরুQuick start

  1. Upload Image চাপুন ও ছবি বাছুন।Press Upload Image and choose a picture.
  2. Image Analysis ও Recommendation panel দেখুন; Auto after upload টিক থাকলে প্ল্যান নিজে প্রয়োগ হয়।Read the Image Analysis and Recommendation panels; with Auto after upload ticked, the plan is applied automatically.
  3. Restored ছবি Original-এর সাথে তুলনা করুন (বড় হলে Actual size চালান)।Compare Restored with Original (turn on Actual size for large images).
  4. পছন্দ না হলে Manual Override-এ ফিল্টার/Kernel/Strength বদলে Apply Selected Filter।If you are not happy, change the filter/Kernel/Strength in Manual Override and press Apply Selected Filter.
  5. Save Result দিয়ে সংরক্ষণ করুন।Save with Save Result.

স্বয়ংক্রিয় মোডAutomatic mode

মাপMeasureThreshold

Exposuremean < 65 → Gamma 1.35; > 195 → Gamma 0.75

প্ল্যানের ক্রম: Impulse → Gaussian noise → Blur → Contrast/Exposure। ধাপ ১ ও ২ Manual Override-এ বসে; পুরো প্ল্যান Pipeline-এ থাকে। এটি heuristic, তাই ফল যাচাই করুন।Plan order: Impulse → Gaussian noise → Blur → Contrast/Exposure. Steps 1 and 2 are placed in Manual Override; the whole plan is in the Pipeline. It is heuristic, so always check the result.

মেট্রিকMetrics

PSNR = 10·log10(255² / MSE) dB

Load Reference দিলে প্রতিটি প্রসেসিংয়ের পর MSE, PSNR ও SSIM Image Analysis-এ আসে। বেশি PSNR/SSIM সাধারণত ভালো, কিন্তু sharpen বা CLAHE-তে PSNR কমলেও ছবি ভালো দেখাতে পারে।With a Reference loaded, MSE, PSNR and SSIM appear in Image Analysis after every run. Higher PSNR/SSIM is usually better, but with sharpening or CLAHE the PSNR can drop even though the image looks better.

সীমাবদ্ধতাLimitations

  • Blind deblurring আন্দাজনির্ভর; ব্লারের ধরন ও কোণ ভুল হতে পারে।Blind deblurring is guesswork; the blur type and angle may be wrong.
  • Detection heuristic, সব ছবিতে নিখুঁত নয়।Detection is heuristic and not perfect on every image.
  • Adaptive Median সরু রেখা মুছে ফেলতে পারে।Adaptive Median can remove thin lines.
  • Deconvolution-এ ringing ও নয়েজ বাড়তে পারে।Deconvolution can cause ringing and amplify noise.
  • ছবির বিভিন্ন অংশে ভিন্ন ব্লার (spatially varying) সামলায় না।Spatially varying blur is not handled.
  • বড় ছবিতে NLM ও Richardson-Lucy ধীর।NLM and Richardson-Lucy are slow on large images.
