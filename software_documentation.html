Image Deblurring & Restoration Studio

Traditional Digital Image Processing filter দিয়ে ছবির noise, blur, low contrast ও exposure সমস্যা ঠিক করার একটি single-file Python desktop সফটওয়্যার। ছবি আপলোড করলে এটি নিজে বিশ্লেষণ করে ফিল্টার প্রস্তাব করে ও প্রয়োগ করে; আপনি সবকিছু ম্যানুয়ালিও নিয়ন্ত্রণ করতে পারেন।

  • স্বয়ংক্রিয় বিশ্লেষণ ও কারণসহ সুপারিশ
  • ১৪টি ফিল্টার: নয়েজ কমানো, deblur, sharpen, contrast/exposure
  • Manual Override: ১টি বাধ্যতামূলক + ১টি ঐচ্ছিক ফিল্টার
  • বহু-ধাপের সম্পাদনযোগ্য Filter Pipeline
  • Test Images: কৃত্রিম নয়েজ/ব্লার দিয়ে পরীক্ষা
  • Reference ছবি থাকলে PSNR / SSIM / MSE
  • বড় ছবির জন্য Actual size ও scroll

ইনস্টল ও চালানো Installation

Librariesopencv-python, numpy, scipy, pillow, scikit-image
OSWindows / macOS / Linux
pip install opencv-python numpy scipy pillow scikit-image
python image_restoration.py

scikit-image না থাকলেও অ্যাপ চলে, তবে Richardson-Lucy কাজ করে না এবং PSNR/SSIM-এর বদলে শুধু MSE দেখায়। Linux-এ tkinter আলাদা: sudo apt install python3-tk।

দ্রুত শুরু Quick start

  1. Upload Image চাপুন ও ছবি বাছুন।
  2. Image Analysis ও Recommendation panel দেখুন; Auto after upload টিক থাকলে প্ল্যান নিজে প্রয়োগ হয়।
  3. Restored ছবি Original-এর সাথে তুলনা করুন (বড় হলে Actual size চালান)।
  4. পছন্দ না হলে Manual Override-এ ফিল্টার/Kernel/Strength বদলে Apply Selected Filter।
  5. Save Result দিয়ে সংরক্ষণ করুন।

Manual Override ট্যাব

কন্ট্রোলবিবরণযেসব ফিল্টারে কাজ করে
Filter (required)প্রথম ও বাধ্যতামূলক ফিল্টার; ১৪টির যেকোনো একটি।—
Kernel size৩–৩১ (বিজোড়)। অর্থ ফিল্টারভেদে ভিন্ন: window / template / PSF size / blur size।Mean, Median, Adaptive Median, Gaussian, Bilateral, Wiener Denoise, NLM, Wiener Deconv, RL, High-Boost
Strength / sigma০.১–৩.০। Gaussian-এ σ, NLM-এ নয়েজ-শক্তি, Deconvolution-এ sharpness, sharpen ফিল্টারে amount, CLAHE-তে clip, Gamma-তে γ।Gaussian, Bilateral, NLM, Wiener Deconv, RL, Laplacian, Unsharp, High-Boost, CLAHE, Gamma
Deconvolution PSFGaussian (defocus) বা Motion।Wiener Deconv, RL
Motion angle০–১৮০° (৫° ধাপ), Motion PSF-এর দিক।Wiener Deconv, RL (PSF = Motion)
Second filter (optional)প্রথম ফিল্টারের ফলের ওপর চলে; নিজস্ব Kernel ও Strength আছে। “None” হলে বন্ধ। PSF/Angle প্রথমটির সাথে শেয়ার।—
Apply on current resultটিক দিলে মূল ছবির বদলে বর্তমান Restored ছবির ওপর চলে (ধাপে ধাপে কাজ)।—

Add to Pipeline →বর্তমান সেটিং Filter Pipeline-এ নতুন ধাপ হিসেবে যোগ করে।—

ফিল্টার রেফারেন্স Filters

FilterকখনKernel / Strength
Meanহালকা Gaussian noiseদ্রুত, এজ নরম
MedianSalt-and-pepperk = window
Adaptive Medianঘন impulsek = সর্বোচ্চ window (≤15)
Gaussianমসৃণ noiseStrength = σ
Bilateralএজ রেখে noiseStrength ×50 = σ color/space
Wiener DenoiseGaussian-ধরনের noisek = window
Non-Local Meansবেশি noise, টেক্সচারk = template; Strength ×10 = h
Wiener DeconvolutionDefocus / motion blurStrength বেশি = শার্প (K = 0.03/s)
Richardson-Lucyনিশ্চিত PSF থাকলেiterations = max(5, 20×s); scikit-image লাগে

Unsharp Maskingমাঝারি ঝাপসাStrength = amount, σ = max(0.3, s)
High-Boostনিয়ন্ত্রিত sharpenk = blur size, Strength = amount
CLAHEকম কনট্রাস্টclip = max(1, 2s), tile 8
Gamma Correctionগাঢ় / অতি-উজ্জ্বলγ = Strength (>1 উজ্জ্বল করে)

স্বয়ংক্রিয় মোড Automatic mode

মাপThreshold
Impulse pixels≥ 0.2% নয়েজ; ≥ 1% হলে Adaptive Median, নইলে Median
Gaussian σ≥ 2.5; < 6 Bilateral, ≥ 6 Non-Local Means
Sharpness<20 very strong, <45 strong, <120 moderate
Motionanisotropy > 0.30 + strong blur
Contraststd < 35 → CLAHE
Exposuremean < 65 → Gamma 1.35; > 195 → Gamma 0.75

প্ল্যানের ক্রম: Impulse → Gaussian noise → Blur → Contrast/Exposure। ধাপ ১ ও ২ Manual Override-এ বসে; পুরো প্ল্যান Pipeline-এ থাকে। এটি heuristic, তাই ফল যাচাই করুন।

ব্যবহার পরিস্থিতি Use cases

পরিস্থিতিকী করবেন
দানাদার (noisy) ছবিTest Images → Add Gaussian Noise, অথবা noisy ছবি আপলোড → Bilateral/NLM স্বয়ংক্রিয়; নয়েজ বেশি হলে NLM-এর Strength বাড়ান।
ছিটানো কালো-সাদা বিন্দুMedian (কম) বা Adaptive Median (ঘন)। সরু রেখা মুছে গেলে Median ব্যবহার করুন।
ক্যামেরা নড়ে ঝাপসাWiener Deconvolution, PSF = Motion, Angle ঠিক করুন, Kernel ≈ ব্লারের দৈর্ঘ্য + ২।
ফোকাস ছাড়া ছবিWiener Deconvolution (Gaussian PSF, Kernel ১১–১৫) বা Unsharp Masking।
গাঢ় / কম কনট্রাস্টGamma Correction (γ>1) বা CLAHE।
নয়েজ + ঝাপসাFilter 1 = NLM/Bilateral, Filter 2 = Unsharp Masking; আরও ধাপ লাগলে Pipeline।
বড় ছবির বিস্তারিত দেখাActual size (scroll) চালু করে স্ক্রল করুন।

মেট্রিক Metrics

PSNR = 10·log10(255² / MSE) dB

Load Reference দিলে প্রতিটি প্রসেসিংয়ের পর MSE, PSNR ও SSIM Image Analysis-এ আসে। বেশি PSNR/SSIM সাধারণত ভালো, কিন্তু sharpen বা CLAHE-তে PSNR কমলেও ছবি ভালো দেখাতে পারে।

সীমাবদ্ধতা Limitations

  • Blind deblurring আন্দাজনির্ভর; ব্লারের ধরন ও কোণ ভুল হতে পারে।
  • Detection heuristic, সব ছবিতে নিখুঁত নয়।
  • Adaptive Median সরু রেখা মুছে ফেলতে পারে।
  • Deconvolution-এ ringing ও নয়েজ বাড়তে পারে।
  • ছবির বিভিন্ন অংশে ভিন্ন ব্লার (spatially varying) সামলায় না।
  • বড় ছবিতে NLM ও Richardson-Lucy ধীর।
